# roblox-joiner

One-click Roblox game joiner for Termux/Android and Linux.

## Install
```bash
curl -fsSL https://raw.githubusercontent.com/rawna22/roblox-joiner/main/install.sh | bash
```

## Usage
```bash
roblox-play 113290951185459
roblox-play https://www.roblox.com/games/113290951185459/Dadu-Anime
```
